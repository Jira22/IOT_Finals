# IoT Final Project

## GPIO pins

- GPIO 23 is for the HC-SR04 trigger
- GPIO 24 is for the ECHO pin in HC-SR04
- GPIO 18 is for the buzzer

## TRIG vs ECHO

- TRIG is an output from the Pi, which sends a short pulse to the sensor.
- ECHO is an input to the Pi, which listens for the sensor’s pulse.
